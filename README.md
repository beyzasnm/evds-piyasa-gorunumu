# EVDS Piyasa Görünümü

[Panoyu aç](https://beyzasnm.github.io/evds-piyasa-gorunumu/)

TCMB EVDS’nin doğrudan yayımladığı USD/TL gösterge alış kuru, net fonlama, toplam rezerv ve yabancı DİBS net akımı. Her seri kendi gözlem tarihi ve frekansıyla gösterilir.

GitHub Actions, `EVDS_API_KEY` depo sırrını kullanarak verileri saatlik kontrol eder. Anahtar veya geçici kaynak erişimi eksikse sayfa son başarılı veri kaydını gösterir.
